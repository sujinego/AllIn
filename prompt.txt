

## 기능 요구사항

### 1. 새 공사 프로젝트 시작에서 지금의 입력사항 누르고 프로젝트 시작하기누르면
 공사일정표 만드는 화면으로 이동

### 2. 공사 일정표 (간트차트)
- 가로 축: 착공일~입주예정일 날짜
- 세로 축: 아래 12개 공정 고정
  기획·설계 / 철거 / 설비·배선 / 목공 / 미장·방수 / 타일 / 도장·도배 / 바닥 / 가구·설비 / 조명 / 실리콘 / 입주청소
- 각 공정의 바(bar)는 해당 공정에 등록된 할일들의 시작일~마감일 범위로 자동 계산
- 주말 셀은 배경색으로 구분
- 날짜 셀 클릭 → 해당 공정+날짜로 할일 추가 폼 열림
- 공정 이름 클릭 → 해당 공정 할일 목록 열림
- 기간이 길면 좌우 스크롤

### 3. 오른쪽 사이드 패널
- 간트차트 오른쪽에 고정 (260px)
- 공정 클릭 시: 세부 공정 리스트 (N건) + 할일 목록
- 날짜 셀 클릭 시: 할일 추가 폼 바로 표시

### 4. 할일 항목 구조
각 할일마다:
- 체크박스 (완료 체크 시 제목 취소선)
- 제목
- 수정 / 삭제 버튼 (아주 작게, 한 줄)
- + 체크 버튼으로 하위 체크리스트 항목 추가 가능
- 시작일 ~ 마감일
- 메모

### 5. 할일 추가/수정 폼
- 할일 제목 (text input)
- 시작일 / 마감일 (date picker, 착공일~입주예정일 범위)
- 메모 (textarea)
- 저장 / 취소 버튼

## DB 스키마 (Supabase)
```sql
-- 프로젝트
create table projects (
  id uuid primary key default gen_random_uuid(),
  start_date date not null,
  end_date date not null,
  created_at timestamptz default now()
);

-- 할일
create table tasks (
  id uuid primary key default gen_random_uuid(),
  project_id uuid references projects(id) on delete cascade,
  phase_id text not null, -- 'demolish', 'tile' 등
  title text not null,
  start_date date not null,
  end_date date not null,
  memo text,
  done boolean default false,
  created_at timestamptz default now()
);

-- 체크리스트
create table checklist_items (
  id uuid primary key default gen_random_uuid(),
  task_id uuid references tasks(id) on delete cascade,
  text text not null,
  done boolean default false
);
```
